## Notes

- Les réponses des apprenants sont enregistrées **dans leur propre navigateur** (localStorage). Rien n'est envoyé ici : ils utilisent le bouton « Exporter mes réponses » pour vous transmettre leur travail.
- Les pages portent `noindex, nofollow` : elles ne sont pas référencées par les moteurs de recherche, mais restent accessibles à toute personne qui a le lien.
- Publication : Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.
